# Карате · турниры

Сайт для ведения карате турниров. Работает в браузере без сервера и без интернета: откройте `index.html` двойным кликом (лучше в Chrome или Edge).

## Как пользоваться

1. **Настройки** — проверьте возрастные группы и веса, время боя, блоки и татами.
2. **Турниры → Новый турнир** — название, дата, место, обложка. Для пробы есть кнопка «Загрузить демо-турнир» (видна, пока турниров нет).
3. **Импорт участников** — Excel с колонками: ФИО, Пол (М/Ж), дата рождения, возраст, вес, кю/дан, регион, город, клуб, тренер, кумите (и необязательная «Страна»). Шаблон можно скачать на странице импорта. Галочка «Сразу распределить» создаёт категории по весам из настроек и строит сетки.
4. **Турнир → дисциплина → татами.** Слева категории, в центре сетка, справа управление боем.
   - Победитель: навести на участника в бою → «Победил». Ошибку можно отменить.
   - «Править сетку»: нажать на двух участников, чтобы поменять их местами.
   - «Участники»: состав категории, добавить позднюю заявку. Сетка строится заново.
   - Переключатель боёв: стрелки или номер боя. Пробел — старт/перерыв, ← → — бои.
   - «Развернуть табло» открывает отдельное окно: перетащите на ТВ и нажмите `F`.

## Правила сетки

- Пары первого круга подбираются по весу (соседи после сортировки).
- При нечётном числе самый тяжёлый проходит во второй круг без боя.
- ID боя = буква категории + номер: A1, A2, … Круги подписаны: 1/16, 1/8, 1/4, полуфинал, финал.

## Где данные

Всё хранится в браузере (localStorage) на этом компьютере. В **Настройки → Данные** можно скачать резервную копию (.json) и загрузить её на другом компьютере.

## Структура

```
index.html, tournament.html, scoreboard.html, settings.html, import.html
css/styles.css         стили сайта
css/scoreboard.css     стили табло
js/core/               общие помощники, хранилище, иконки
js/domain/             логика: сетка, категории, импорт Excel, таймер и табло, демо-данные
js/pages/              код каждой страницы (tournament/ — экран турнира по частям)
vendor/xlsx.full.min.js  SheetJS для чтения Excel (лицензия Apache 2.0, vendor/xlsx.LICENSE)
img/                   обложки турниров
```

Шрифты (Golos Text, Unbounded, JetBrains Mono, Oswald) грузятся из Google Fonts; без интернета будут системные.
